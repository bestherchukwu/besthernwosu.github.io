HIGH AVAILABILITY

Active-Active Infrastructure Architecture

Architecture initiative focused on improving application availability and reducing infrastructure single points of failure.

Key activities

  • Reviewed existing architecture and failure points.
  • Assessed application and database dependencies.
  • Evaluated DNS, traffic distribution and network requirements.
  • Assessed database replication and failover requirements.
  • Developed implementation and testing considerations.

Architecture concept

USERS → DNS / TRAFFIC DISTRIBUTION
             |
       +-----+-----+
       |           |
       v           v
   ENVIRONMENT A ↔ ENVIRONMENT B
       |           |
       +-----+-----+
             |
        DATABASE LAYER

Outcome

Established an architectural approach for improved availability, resilience and fault tolerance.
